# Вкладка Video: MiniMax H3 через FreeVideo

Дата: 2026-10-19. Задание: вкладка Video с генерацией видео MiniMax H3 в
режимах text-to-video, image-to-video, first-last frame и по референсам;
потребление памяти — как у FreeVideo (8 ГБ VRAM / 16 ГБ RAM минимум);
максимум автоматизации по «Вайб-монтажу с ИИ»; кнопка «В видео» на
вкладках изображений.

## Исследование (итоги)

| Источник | Вывод |
|---|---|
| `E:\MINIMAX` | H3 на нативных нодах ComfyUI 0.30.1: DiT int8 ConvRot 21 ГБ ×2 (FL2VA и Ref2VA не взаимозаменяемы), энкодер Qwen3-VL-32B NVFP4 15.7 ГБ, видео-VAE, аудио-VAE. 864×480×124 кадра, 20 шагов: 423 с, пик 22 ГБ. |
| FreeVideo v0.4.15 (`71129a7`) | Движок только для H3, а точнее для дистиллята VDN-H3 на 8 шагов без CFG. Использует int8 ConvRot W8A8 на Ampere, поблочную подкачку на двух CUDA-потоках с pinned RAM, таблицы AdaLN вместо проекций (−26 ГБ), тайловый VAE «блок снаружи, тайлы внутри», энкодер в отдельном процессе и двухпроходный сэмплинг 8+3 шага с латентным апскейлом. Окружение своё: Python 3.12.3, torch 2.13 cu130, пропатченный diffusers. Портировать 400 модулей значит получить хрупкую копию, поэтому FreeVideo подключается как внешний движок в своём окружении внутри проекта. |
| Вайб-монтаж (PDF) | Документ про агентный монтаж, а не про генерацию. Из него берём порядок «раскадровка → черновик → финал», карточку шота (задача / время / кадр / движение / звук / выход), типовые структуры роликов, правила переходов и звука, правило «вертикаль — новая композиция», а также версии шотов и перегенерацию одного шота. |
| skill `minimax-h3-prompt` | Структура промпта H3: поля, строки выравнивания I2VA/FL2VA/L2VA, метки Ref2VA, сетка кадров 17k+5 при 24 fps. |

## Архитектура

```
fooocus_qwen/video/          ← новый пакет; torch в процесс приложения не тянет
  geometry.py                кадры 17k+5, холсты (кратность 32), уровни качества
  request.py                 VideoRequest: режим, промт, кадры, референсы, длительность…
  prompt_h3.py               сборка промта H3 из свободного текста + строки выравнивания
  engine.py                  установка FreeVideo, драйвер-подпроцесс, прогресс, отмена
  driver/freevideo_driver.py исполняется В ОКРУЖЕНИИ FreeVideo: comfy_bridge.generate
  assemble.py                ffmpeg: последний кадр, склейка шотов с переходами, громкость
  storyboard.py              раскадровка брифа языковой моделью → список шотов
fooocus_qwen/ui/tab_video.py вкладка
resources/prompts/video_*.md системные промты буста видео и раскадровки
```

Видеокарта одна, поэтому перед видео выгружается Qwen (`Studio.unload`), и
FreeVideo планирует память по реально свободной VRAM. Очередь — та же
группа `GPU_CONCURRENCY_ID`.

## Подзадачи

1. Установка FreeVideo в `FreeVideo/` (gitignore): закреплённый тег,
   `--network official`, энкодер берётся из `E:\MINIMAX` (`--reuse-models`),
   все временные каталоги внутри. Шаг в `install.ps1/sh` и ключ
   `--setup-video`, плюс кнопка установки на вкладке.
2. `geometry`, `request`, `prompt_h3` и тесты (сабагент).
3. `assemble` (ffmpeg) и тесты (сабагент).
4. Драйвер и `engine`: подпроцесс, JSON-события, прогресс, отмена через
   CTRL_BREAK, длинные ролики через `chain_plan` и `--continue-from`.
5. Вкладка Video: режимы, кадры, референсы с метками, длительность в
   секундах (кадры показываются), разрешение и соотношение, уровень
   качества, сид, LoRA, буст промта H3, сохранённые промты, результат с
   плеером, «последний кадр → первый кадр следующего», «Стоп».
6. Раскадровка: бриф → шоты (таблица) → генерация всех с цепочкой кадров
   → склейка с переходами → итоговый ролик.
7. Кнопки «В видео» на генерации и правке; видео в галерее.
8. Замер памяти и времени на RTX 3090 против заявленного FreeVideo, в том
   числе с ограничением 8 ГБ / 16 ГБ.
9. Документация (USAGE, ARCHITECTURE, README ×2, CHANGELOG, research),
   память, ui_check, pytest, ruff.
