# Опыты

Разовые скрипты, которыми выяснялось, **как** должна работать оболочка,
когда ответа не было ни в документации модели, ни в исходнике пайплайна.
От инструментов в каталоге выше они отличаются назначением: те обслуживают
работу (замер, дымовой прогон), эти — однажды ответили на вопрос и остались
как доказательство ответа.

Держатся в дереве намеренно. Каждый вывод в `docs/research/` опирается на
конкретные числа, и без скрипта их нельзя ни перепроверить, ни уточнить при
смене версии модели.

| Скрипт | Вопрос | Ответ |
|---|---|---|
| `mask_protocol.py` | Резкая маска или растушёванная? Объяснять ли маску в промте? | Резкая; объяснять вредно — модель начинает строить прозрачность |
| `mask_local.py` | Какая кодировка маски точнее: пара «исходник + маска» или дырка в альфе? | Обе хороши при резкой маске; слово «прозрачность» в промте её включает даже с отрицанием |
| `outpaint.py` | Чем чинить прозрачную дорисовку полей? | Промтом: описание сцены вместо описания операции, с нуля до ста процентов непрозрачности |

Подробности и таблицы — `docs/research/2026-09-22-maska-kak-alfa.md`.

Запуск (из корня проекта):

```powershell
.venv\Scripts\python tools\experiments\outpaint.py
```
